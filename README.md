# rustc-dep-info

Parse, print, and manipulate dep-info files used by `rustc` and `cargo`.

The parsing and printing functionality aims to be compatible with `rustc` and `cargo` specifically,
and is not meant to be generally applicable outside of that context.

In particular, the crate aims to uphold the following properties:

- **recoverable**: `parse(print(c)) == c` for every `c: Contents` value
- **transparent**: `cargo_parse(print(parse(t))) == cargo_parse(t)` for every `t: Text`
  dep-info generated by `rustc`

However, the crate explicitly does _not_ aim to uphold the following properties:

- **constrained**: `cargo_parse(print(c))` succeeds for every `c: Contents` value

Here `parse` and `print` are this crate's implementations, and `cargo_parse` is Cargo's own.

```rust
let info: rustc_dep_info::Contents = r#"
app: src/main.rs
# env-dep:MODE=debug
"#
.parse()?;

assert!(info.sources.contains_key("src/main.rs"));
assert_eq!(info.env.get("MODE"), Some(&Some("debug".into())));
```

Features:

- `rustc_dep_info::Contents`: sources with optional checksums, targets, and environment variables.
- `Contents::read_file` and `Contents::write_file` for file I/O.
- `FromStr`, `TryFrom<&str>`: parse dep-info text already in memory.
- `Display`: print dep-info contents back into text format.
